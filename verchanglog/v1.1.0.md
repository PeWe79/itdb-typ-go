# itdb v1.1.0 版本更新日志

**发布日期**: 2026-09-17  
**提交数量**: 10 次提交  
**版本类型**: 功能更新（Minor Release）

---

## 📋 版本概述

v1.1.0 围绕三条主线迭代：统计报表支持数据导出并细化导出权限；数据库导入全面优化——导入前检测文件占用、预备份可携带上传文件打包为 zip、旧库迁移规则完善（硬件维护日志不再迁移、硬件类型按当前默认重建）；资产管理列表新增列显示自定义，支持勾选显隐与拖拽排序，并联动搜索范围与导出字段。

本版本不包含数据库表结构变更，v1.0.0 用户可直接替换升级。

---

## ✨ 新增特性

### 统计报表导出

- 统计报表支持将报表数据导出为文件，并优化数量报表布局
- 报表导出权限细化：导出操作按各报表对应的资源读取权限校验并记录审计

### 资产列表列显示自定义

- 资产管理每个菜单的新增按钮右侧新增「列显示」选择项，默认展示全部列
- 支持勾选取消不需要的列，至少保留一列，全取消时给出提示
- 支持拖拽调整列顺序，拖动时在两项之间显示插入位置横线指示，落位即按横线位置插入
- 列显示偏好按资源保存在浏览器本地，刷新与下次进入自动保持
- 搜索框基于当前显示的列进行匹配，隐藏的列不再参与搜索
- 导出窗口的「导出字段」改为跟随当前显示列及其顺序，不再固定为全量字段

### 数据库导入预备份增强

- 导入前的预备份在当前数据库引用了上传文件时，自动将数据库与文件一并打包为 zip（文件统一放在包内 `files` 目录）；未引用文件或引用文件均不存在时仍仅备份 `.db` 文件
- 导入成功后自动清理已随预备份打包的上传文件，避免残留在上传目录；导入失败回滚路径不删除文件，保证可完整恢复

## 🐛 Bug 修复

- 修复数据库文件被外部工具（如 SQLite 管理工具）占用时导入失败缺乏明确提示的问题：导入前自动检测占用，命中时返回「当前数据库文件正被外部工具使用，请先关闭后再导入」，并自动恢复服务
- 修复数据库导入成功后提示不显示及重复跳转登录页的问题：导入成功现在弹出提示并由会话机制单次跳转登录页
- 修复旧项目数据库导入后硬件维护日志（actions 操作记录）仍被带入的问题：维护日志不再迁移，导入后保持为空
- 修复从旧库导入硬件类型时编号与「支持软件」默认值混乱的问题：迁移后编号 1-5 固定为内置类型（仅「服务器」默认支持软件），旧库其余类型从 6 连续追加，重名自动忽略，硬件记录的类型编号同步映射
- 修正 Nginx 将资产页面路由误判为静态资源导致的 404

## 🔧 重构优化

- 移除与内置硬件类型新默认值语义冲突的「全部类型强制支持软件」启动兜底逻辑
- 导入预备份由固定仅备份数据库文件改为复用定时备份的文件引用检测与打包能力（`CreateImportBackup`）
- 新增前后端本地服务管理脚本，简化开发环境启动
- CI 升级 QEMU、Buildx 与 Release Action 至 Node 24 运行时

## 🔄 API 变更

- `POST /api/import/database`：当前数据库文件被外部工具占用时返回 `409` 并提示先关闭再导入；导入成功后服务端会清理随预备份打包的上传文件
- 报表导出操作按各报表对应资源的读取权限校验（涉及报表导出相关接口的权限行为细化）
- 无新增或删除接口

---

## 📊 数据库变更

- 无表结构变更
- 内置种子数据调整：新初始化库的内置硬件类型中仅「服务器」默认支持软件（`hassoftware=1`），存储、交换机、电话、安防默认为否；该调整仅影响全新初始化的库，存量库可在「资料管理 → 硬件类型」中自行调整
- 旧项目数据库导入行为变化：硬件维护日志（`actions` 表数据）不再迁移；硬件类型按「编号 1-5 固定内置默认 + 旧库其余类型去重追加」重建并同步硬件记录的类型编号

## 🔄 升级说明

**从 v1.0.0 升级**（无需数据库迁移脚本）：

- Docker：拉取 `v1.1.0` 镜像或保持 `latest` 标签重新拉起容器即可，数据目录挂载方式不变
- Release 二进制：从 [GitHub Releases](https://github.com/zyx3721/itdb-new/releases) 下载对应平台包替换，前端 SSR 产物包同步替换

**升级后说明**：

1. 存量数据库的内置硬件类型「支持软件」默认值不受本版本影响，如需调整请在「资料管理 → 硬件类型」中修改
2. 再次从旧项目 PHP itdb 导入数据库时，注意维护日志不再迁移、硬件类型将按新规则重建（原类型编号会映射到新编号）
3. 导入数据库前请关闭可能占用数据库文件的 SQLite 管理工具，否则导入会被拦截并提示
