# itdb v1.2.0 版本更新日志

**发布日期**: 2026-09-18  
**提交数量**: 9 次提交

## 📋 版本概述

v1.2.0 带来两大核心能力：**企业微信扫码登录与账号绑定体系**——认证配置新增企业微信提供者（企业 ID、AgentID、加密 Secret 与可留空的回调地址前缀），登录页支持跳转企业微信扫码授权，用户可在右上角菜单绑定/解绑企微账号，扫码有效期可在基础配置-安全时效中调整；**审计日志全面增强**——新增时间范围筛选（精确到秒的自研范围选择器）与按筛选结果清空能力，并优化深浅色主题下的配色与弹层背景。

共 9 次提交，前后端与文档同步更新，Swagger 产物已重新生成。

---

## ✨ 新增特性

- **企业微信扫码登录**：登录方式下拉框新增「企业微信」，选择后当前窗口跳转企业微信 Web 扫码页，扫码确认后按绑定关系自动登录并签发会话；未绑定的企微账号将被拒绝并提示先绑定
- **企微账号绑定**：右上角用户菜单在「修改密码」与「退出系统」之间新增「绑定企微/解绑企微」（仅企微认证启用时显示），弹窗扫码完成绑定后实时刷新绑定状态；一个企微账号仅可绑定一个用户，重复绑定其他用户返回 409；绑定/解绑/扫码登录均写入审计日志
- **企微扫码有效期可配置**：「系统配置 → 基础配置 → 安全时效」新增「企业微信扫码有效期」（默认 5 分钟，范围 1-60 分钟），持久化到数据库，授权 state 超时需重新扫码
- **审计日志时间范围筛选**：「全部模块」左侧新增时间范围选择器，双月并排日历 + 手动输入行（日期时间精确到秒），支持起止自动纠正与当前时间自动补全，与模块、结果、关键字筛选叠加生效
- **审计日志按筛选结果清空**：导出按钮右侧新增半透明红「清空」按钮，图三样式确认弹窗（清空日志记录/清空后不可恢复）确认后按当前筛选结果精确删除；清空操作自动补记一条「清空审计日志」审计事件，归属新增的「审计日志」模块

## 🐛 Bug 修复

- 修复企业微信扫码有效期保存与恢复默认未生效的问题：安全时效字段白名单遗漏新字段，导致前端未提交该值
- 修复审计日志工具栏窄屏时换行错位：改为单行横向滚动并隐藏滚动条（其余页面工具栏行为不变）
- 修复深色模式下「审计日志」「系统配置」模块徽章对比度不足：分别调整为亮洋红与亮黄绿配色，不与既有模块配色冲突
- 修复深色模式下日期选择器弹层背景过黑：提亮为与卡片同层的深海军蓝，日期格子层次清晰

## 🔧 重构优化

- 时间范围选择器的日期与时间字段改为自研弹层（单月日历、时/分/秒三列选择器），彻底替代浏览器原生弹层，深浅色主题统一
- 登录页企业微信扫码卡片高度与账号密码模式对齐，切换登录方式不再跳动
- 认证配置显示名称改为只读展示（AD/LDAP 与企业微信一致）
- 认证配置面板重构为双提供者管理器：侧栏并列 AD/LDAP 与企业微信卡片，按选中切换详情面板

## 🔄 API 变更

- 新增公开接口：`GET /api/auth/wecom/authorize`（获取扫码登录地址）、`POST /api/auth/wecom/callback`（扫码回调登录）
- 新增需认证接口：`GET /api/auth/wecom/bind-url`（绑定扫码地址）、`POST /api/auth/wecom/bind`（绑定）、`DELETE /api/auth/wecom/bind`（解绑）
- 新增配置接口：`GET /api/settings/auth/wecom`、`PUT /api/settings/auth/wecom`（settings.auth.read / settings.auth.manage 权限）
- 新增审计接口：`POST /api/history/clear`（按筛选结果清空审计日志，audit.manage 权限）
- 行为扩展：`GET /api/auth/providers` 返回企业微信条目；`GET /api/auth/me` 新增 `wecomBound` 字段；`PUT /api/settings/base` 安全区块新增 `wecomStateTtlMinutes`（1-60）
- 权限模型无新增权限点：企微配置复用认证配置读写权限，清空审计复用管理审计权限

---

## 📊 数据库变更

- 新增表 `settings_user_wecom`（user_id 主键、wecom_userid 唯一、bound_at），服务启动时自动创建
- `settings_auth_providers` 预置行新增 `id='wecom'`（默认关闭），启动时自动补齐
- `history` 新增审计模块取值 `audit`（企业微信绑定/解绑与清空审计日志事件）
- 旧项目数据库导入恢复清单补入 `settings_user_wecom`，绑定关系随迁移保留

## 🔄 升级说明

**从 v1.1.2 升级**（无需数据库迁移脚本）：

- Docker：拉取 `v1.2.0` 镜像或保持 `latest` 标签重新拉起容器即可
- Release 二进制：从 [GitHub Releases](https://github.com/zyx3721/itdb-new/releases) 下载对应平台包替换

**升级后说明**：

1. 首次启动自动创建 `settings_user_wecom` 表并预置企业微信提供者配置行，无需手工 SQL
2. 启用企业微信扫码登录需在企业微信管理后台创建自建应用，配置可信回调域名与企业可信 IP，再到「系统配置 → 认证配置 → 企业微信」填写并启用，详见《完整手册》7.8 节
3. 审计日志新增的时间范围筛选、清空按钮与「审计日志」模块徽章无需额外配置；清空审计需要「管理审计」权限
4. 其余行为与 v1.1.2 一致
