# itdb v1.3.3 版本更新日志

**发布日期**: 2026-09-22  
**提交数量**: 8 次提交  
**版本类型**: 功能新增与体验优化（Patch Release）

---

## 📋 版本概述

v1.3.3 为后端带来完整的命令行参数支持与版本信息能力：二进制文件现在支持 `-h` 查看帮助、`-v` 查看版本、以及 9 个与既有环境变量一一对应的配置参数，发布产物（CI 二进制与 Docker 镜像）自动注入版本、commit 与构建时间。同时新增登录失败锁定的安全时效配置且 admin 不受限，修复 SSR 场景品牌图标与名称的回退闪烁，并统一品牌 favicon 设计。

---

## ✨ 新增特性

- **后端命令行参数**：新增 `-addr` / `-port` / `-db` / `-upload-dir` / `-jwt-secret` / `-history-limit` / `-session-ttl` / `-cors-origins` / `-env` 参数，与既有环境变量一一对应，显式传入的参数优先于环境变量与 `.env` 文件；`-env` 可指定自定义 `.env` 配置文件路径
- **版本信息能力**：新增 `-v` / `-version` 参数显示版本、commit、构建时间与 Go 版本，`-h` / `--help` 输出对齐缩进的帮助说明；后端启动日志携带版本号
- **发布产物版本注入**：CI 交叉编译二进制与 Docker 镜像构建时通过 `-ldflags -X` 自动注入版本号（tag 名）、commit 与构建时间
- **登录失败锁定可配置**：平台基础设置新增 `loginMaxFailures`（连续失败次数，默认 5）与 `loginLockoutMinutes`（锁定时长，默认 2 分钟）两个安全时效配置项，admin 账户不受锁定限制

## 🔄 升级说明

**从 v1.3.2 升级**（无需数据库迁移脚本）：

- Docker：拉取 `v1.3.3` 镜像或保持 `latest` 标签重新拉起容器即可
- Release 二进制：从 [GitHub Releases](https://github.com/zyx3721/itdb-new/releases) 下载对应平台包替换

**升级后可选**：

1. 执行 `./itdb -v`（Windows 为 `itdb.exe -v`）可验证运行版本与构建信息
2. 如需通过命令行传参启动，参考 `./itdb -h`；不传参数时行为与 v1.3.2 完全一致
3. 登录失败锁定默认策略为 5 次失败锁定 2 分钟，admin 不受限；可在平台设置中调整
