# itdb v1.2.1 版本更新日志

**发布日期**: 2026-09-18  
**提交数量**: 2 次提交  
**版本类型**: 问题修正（Patch Release）

---

## 📋 版本概述

v1.2.1 修复 v1.2.0 企业微信认证的两处交互体验问题：认证启用状态变更后右上角绑定入口需要刷新页面才显示；绑定弹窗无法自动关闭、扫码回调过程闪现登录页、跳转企微后返回登录页按钮卡在「处理中」。同时将企微登录、绑定、解绑与注销的审计详情文案优化为更完整的表述。

本版本不包含数据库表结构与 API 变更，v1.2.0 用户可直接替换升级。

---

## 🐛 Bug 修复

- 修复企微认证启用/停用保存后，右上角「绑定企微/解绑企微」入口需要刷新页面才更新的问题：认证配置保存成功后即时通知布局强制刷新公开认证方式状态，入口显隐实时联动
- 修复企微绑定弹窗成功后无法自动关闭的问题：绑定成功并通知主窗口后自动关闭弹窗
- 修复扫码登录回调期间闪现完整登录页的问题：回调处理改为独立的居中加载视图（正在处理企业微信授权），失败时显示原因与「返回登录」按钮
- 修复跳转企业微信授权页后返回登录页，扫码按钮卡在「处理中」无法再次点击的问题：浏览器往返缓存恢复时重置按钮状态，并增加安全超时兜底

---

## 🔧 重构优化

- 企微相关审计详情文案优化（仅对新写入的记录生效，历史记录按原值显示）：
  - 扫码登录失败：`使用企业微信方式登录失败：<原因>` / `企业微信账号 <userid> 使用企业微信认证方式登录失败：<原因>`（失败时系统用户名尚不可知，以企微 userid 标识，审计目标同步记录）
  - 扫码登录/注销成功：`使用企业微信认证的系统用户 <用户名> 登录成功` / `…注销成功`
  - 绑定成功：`系统用户 <用户名> 绑定企业微信账号 <userid> 成功`
  - 解绑成功：`系统用户 <用户名> 已解除绑定企业微信账号 <userid>`（解绑前自动查询被解绑的企微账号）

## 🔄 升级说明

**从 v1.2.0 升级**（无需数据库迁移脚本）：

- Docker：拉取 `v1.2.1` 镜像或保持 `latest` 标签重新拉起容器即可
- Release 二进制：从 [GitHub Releases](https://github.com/zyx3721/itdb-new/releases) 下载对应平台包替换

**升级后说明**：

1. 审计详情新文案仅对升级后新产生的记录生效，v1.2.0 的历史记录按原值展示
2. 其余行为与 v1.2.0 一致
